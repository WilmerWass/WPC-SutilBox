## Regla documental

La documentación debe distinguir siempre entre:

- **existente:** confirmado en el código;
- **en desarrollo:** trabajo activo;
- **pendiente:** previsto pero no implementado;
- **futuro:** idea o etapa posterior.

No se debe presentar una idea futura como una función actual.
