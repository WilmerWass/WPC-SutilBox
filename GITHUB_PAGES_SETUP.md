# Activar GitHub Pages para WPC-SutilBox

Los documentos Markdown están preparados para publicarse desde la carpeta `/docs`.

En GitHub:

1. Abrir **Settings** del repositorio.
2. Entrar en **Pages**.
3. En **Build and deployment**, seleccionar **Deploy from a branch**.
4. Seleccionar la rama `main`.
5. Seleccionar la carpeta `/docs`.
6. Guardar.

La página del proyecto será:

`https://wilmerwass.github.io/WPC-SutilBox/`

`docs/index.md` funciona como portada y `docs/_config.yml` define el sitio Jekyll.

GitHub Pages debe configurarse en el repositorio; crear los archivos no activa por sí solo la publicación.
